# Honer AI 10.0 · iPhone

Нативное приложение SwiftUI для iPhone 13 / 13 mini / 13 Pro / 13 Pro Max и более новых iPhone, iOS 16.0+. Интерфейс опирается на предоставленные скриншоты: тёмный чат, боковая история, меню сообщений, настройки и панель вложений. Название приложения — **Honer AI**, знак — собственная буква X.

## Установка

Подпишите IPA из комплекта релиза своим сертификатом и установите на iPhone. Это приложение для iOS arm64; APK для его установки не используется. API-ключ владельца включается в ресурс приложения при сборке, отдельный сервер для работы клиента не требуется.

Идентификатор приложения остаётся `com.honorpk.agent.ios`. При обновлении поверх прежней версии с тем же идентификатором и совместимой подписью iOS сохраняет контейнер приложения. Удаление приложения удаляет его локальные данные; резервную копию можно заранее сохранить через настройки.

При первом запуске укажите имя, ник или позывной. Оно сохраняется в локальном профиле и учитывается в следующих запросах. Имя можно изменить в настройках; серверная регистрация не нужна.

## Чат и история

- Потоковые ответы DeepSeek Flash, переключатель рассуждения, раскрываемое описание рассуждения, длительность, остановка и повтор ответа. Если модель присылает английский текст, приложение запрашивает перевод на русский; переведённое описание рассуждения отмечается в интерфейсе.
- Копирование, выделение текста, редактирование своего сообщения, оценки ответа, чтение вслух и системное меню «Поделиться». Редактирование и повтор ответа заменяют последующие сообщения в текущем чате.
- Боковая история с поиском по названиям и содержимому, закреплением, переименованием, выбором нескольких чатов и удалением.
- Меню чата: поделиться перепиской, найти текст в текущем чате, открыть загруженные файлы, закрепить, архивировать или удалить. Архивированные чаты доступны в настройках и могут быть восстановлены.
- Ветка создаёт отдельный чат от выбранного сообщения, сохраняя исходную переписку. Общие файлы остаются доступны, пока на них ссылается хотя бы один чат или черновик.
- Память Honer AI сохраняет только явно добавленные пользователем факты и предпочтения: до 50 записей по 1000 символов. Записи можно добавлять через «Запомнить» в меню сообщения, редактировать, удалять и временно отключать. Очистка истории сохраняет память; для неё предусмотрена отдельная очистка.

## Вложения и просмотр

Камера, альбом и приложение «Файлы» открывают настоящие системные средства выбора. Панель показывает миниатюры недавних фото и видео после разрешения доступа к медиатеке. Выбор отдельных материалов через «Альбом» доступен без полного доступа к медиатеке.

Фото передаются модели как изображения. PDF и текстовые файлы обрабатываются на устройстве; для изображений и сканированных страниц доступно распознавание текста. Документы ограничены 20 МБ и 160 000 извлечённых символов; PDF — 80 страницами.

Видео MP4/MOV/M4V с поддерживаемым iOS кодеком ограничены **2 минутами и 40 МБ**. Оригинал сохраняется для воспроизведения и резервной копии. Для ответа модель получает до шести кадров с отметками времени. Это анализ выбранных кадров, а не непрерывный просмотр всего ролика; звук видео не распознаётся и не передаётся как аудио. Фото, видео и документы можно открыть из сообщения или списка загруженных файлов.

## Голос

Переключитесь на голосовой ввод, удерживайте кнопку и говорите. При отпускании микрофон останавливается; приложение ждёт завершения распознавания не более 1,2 секунды и отправляет полученный текст. Сдвиг вверх отменяет запись. Индикатор уровня реагирует на реальный сигнал микрофона. При уходе приложения в фон запись прекращается.

Чтение ответов использует **установленные русские голоса iOS**. В режиме «Лучший доступный» выбирается голос наивысшего доступного качества; в настройках можно выбрать конкретный голос и послушать его. Улучшенный или премиальный голос должен быть загружен в настройках iPhone, чтобы появиться в списке. Точный тембр из официального приложения DeepSeek в эту сборку не входит.

Перед озвучиванием убираются декоративные emoji, разметка Markdown, блоки кода, URL и числовые ссылки на источники. Автоматическое чтение включается кнопкой динамика вверху чата. Язык диктовки настраивается отдельно от русского голоса чтения.

## Поиск и источники

Поиск обращается к Bing RSS и DuckDuckGo, отбирает результаты и пытается прочитать текст доступных страниц. Можно передать прямую ссылку. Для погодных запросов используются реальные данные Open-Meteo. Ответ получает найденные выдержки, прочитанное содержимое или структурированные данные; карточки источников содержат настоящие ссылки.

Интерфейс различает прочитанную страницу и результат, для которого доступна только поисковая выдержка. Если поисковые сервисы не дали результатов, модель может предложить адреса для проверки: такой адрес становится источником только после успешного получения страницы. Недоступные страницы, ограничения сайтов и отсутствие сети могут помешать поиску; придуманные выдержки не подставляются вместо результатов.

## Настройки и данные

Доступны локальный профиль, русский/английский интерфейс, размер текста, персональные инструкции, память, голоса, язык диктовки, архив и управление данными. Инструкции сохраняются автоматически и применяются к следующим сообщениям. В разделе «Персонализация» есть видео с примером настройки стиля и настоящего ответа.

Внешний вид можно выбрать вручную. **Пункт «Система» в версии 10.0 тоже включает тёмную тему**, как задано в требованиях этой сборки; светлая тема включается пунктом «Светлый».

История загружается и сохраняется в фоне, а экспорт/импорт обрабатывает файлы асинхронно. JSON-копия включает чаты, архив, память и вложения; общие файлы веток записываются один раз. Ограничения копии: 100 МБ JSON и до 64 МБ вложенных файлов. Импорт объединяет данные с существующей историей и памятью.

Синхронизация между устройствами не реализована. iOS может прервать генерацию в фоне; полученная часть ответа сохраняется, после возвращения можно повторить запрос.

## Сборка IPA

Нужен macOS с Xcode и XcodeGen:

```bash
brew install xcodegen
bash scripts/build-unsigned.sh
```

Сценарий создаёт проект, собирает Release для физического iPhone без подписи и упаковывает `Payload`. Его текущий выходной файл — `build/Honor-PK-Agent-unsigned.ipa`; историческое имя файла не меняет название Honer AI на устройстве.

Для работы в Xcode выполните `xcodegen generate` и откройте `HonorPKAgent.xcodeproj`. Имена проекта, target и каталогов `HonorPKAgent` сохранены для совместимости. Версия берётся из `project.yml`: `MARKETING_VERSION: 10.0`, `CURRENT_PROJECT_VERSION: 10`.

Настройки API находятся в `HonorPKAgent/DeepSeekConfig.plist`: `APIKey`, `BaseURL`, `Model`. В комплекте исходников владельца ресурс настроен. Если ресурс отсутствует, сценарий копирует пример; перед сборкой работающего клиента заполните его. Workflow `.github/workflows/ios.yml` получает ключ из секрета `DEEPSEEK_API_KEY` и включает его в приложение.

## Проверка конкретной сборки

Подтверждённые результаты, версии симуляторов и ограничения проверки фиксируются в [VALIDATION.md](VALIDATION.md). Этот README описывает возможности исходного кода и не заменяет отчёт CI.

В `Tests` проверяются потоковые события, реальные форматы запросов, история, память, ветки, архив, файлы, извлечение кадров и очистка текста для озвучивания. `UITests` проверяет экраны и взаимодействия; отдельные сценарии выполняют настоящие запросы к модели. Тестовые ответы, голосовая имитация для жестов и начальные переписки доступны только в Debug и не включаются в Release.

Подпись сертификатом владельца, физические камера и микрофон, маршрутизация звука, системные разрешения и поведение в мобильной сети проверяются на устройстве. Симулятор не подтверждает одинаковое поведение всех поддерживаемых iPhone и версий iOS.
