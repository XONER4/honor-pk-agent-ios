# Honor PK Агент · iPhone

Нативное приложение SwiftUI для iPhone 13 / 13 mini / 13 Pro / 13 Pro Max и более новых iPhone, iOS 16.0+. Иконка и название Honor; интерфейс основан на восьми предоставленных скриншотах. Отдельный идентификатор `com.honorpk.agent.ios` позволяет установить его рядом с Honor PC Agent.

## Установка

Подпишите `Honor-PK-Agent-unsigned.ipa` своим сертификатом через используемое вами средство подписи и установите на iPhone. Архив уже содержит приложение для устройства arm64. Приложение не требует отдельного сервера. Предоставленный API-ключ встроен в сборку.

## Возможности

- Потоковые ответы DeepSeek Flash, переключатель рассуждения, раскрывающийся блок рассуждения и его длительность, остановка и повтор ответа.
- Чаты на устройстве: поиск по названиям и сообщениям, закрепление, переименование, выбор нескольких чатов и удаление.
- Меню удержания: копирование, выделение текста, редактирование собственного сообщения с пересозданием ветки, оценка ответа, чтение вслух и системное меню «Поделиться».
- Фото из камеры и альбома передаются модели как изображения. Текстовые документы и PDF извлекаются на устройстве. Голосовой ввод использует распознавание речи iOS, чтение ответов — системные голоса.
- Поиск получает реальные заголовки, ссылки и выдержки Bing RSS. Ответ учитывает эти выдержки и показывает источники; полные страницы автоматически не скачиваются. Доступность поиска зависит от Bing и сети.
- Настройки: локальное имя, экспорт/импорт переписки, очистка истории, русский/английский интерфейс, тема, размер текста, персональные инструкции, голос и язык диктовки.

История хранится локально. Синхронизация между устройствами и серверная регистрация аккаунта не добавлены. Генерация может прерваться при уходе iOS-приложения в фон; полученный текст сохраняется и доступен повтор ответа.

## Сборка

Нужен macOS с Xcode и XcodeGen (`brew install xcodegen`). Откройте `HonorPKAgent.xcodeproj` либо выполните:

```bash
bash scripts/build-unsigned.sh
```

Результат: `build/Honor-PK-Agent-unsigned.ipa`. Если меняются состав или настройки проекта, выполните `xcodegen generate`. На GitHub сборку выполняет workflow `.github/workflows/ios.yml`; ключ берётся из секрета `DEEPSEEK_API_KEY` и включается в ресурс приложения. В исходном архиве для владельца ресурс `HonorPKAgent/DeepSeekConfig.plist` уже настроен.

## Проверки

Тесты в `Tests` проверяют обработку SSE, запросы, историю и поиск. `UITests` открывают главные состояния приложения и сохраняют снимки настоящего симулятора iOS; один тест отправляет короткий реальный запрос в DeepSeek и требует настроенного ключа. Всего 15 тестов прошли на симуляторе iPhone 13. Аргументы `-UITestWelcome` и `-UITestDemo` предназначены исключительно для изолированного UI-тестирования; обычный запуск не создаёт демонстрационных переписок.

Для финального номера сборки, результатов проверки и известных ограничений см. `VALIDATION.md`.
