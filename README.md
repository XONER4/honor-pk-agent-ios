# Honor PK Агент 1.1 · iPhone

Нативное приложение SwiftUI для iPhone 13 / 13 mini / 13 Pro / 13 Pro Max и более новых iPhone, iOS 16.0+. Иконка и название Honor; интерфейс основан на восьми предоставленных скриншотах. Отдельный идентификатор `com.honorpk.agent.ios` позволяет установить его рядом с Honor PC Agent.

## Установка

Подпишите `Honor-PK-Agent-unsigned.ipa` своим сертификатом через используемое вами средство подписи и установите на iPhone. Архив уже содержит приложение для устройства arm64. Приложение не требует отдельного сервера. Предоставленный API-ключ встроен в сборку.

## Возможности

- Потоковые ответы DeepSeek Flash, переключатель рассуждения, раскрывающийся блок рассуждения и его длительность, остановка и повтор ответа.
- Чаты на устройстве: поиск по названиям и сообщениям, закрепление, переименование, выбор нескольких чатов и удаление.
- Меню удержания: копирование, выделение текста, редактирование собственного сообщения, оценка ответа, чтение вслух и системное меню «Поделиться». Редактирование или повтор ответа заменяет последующие сообщения в текущем чате.
- **Ветки разговора.** Создайте новый чат от выбранного сообщения и попробуйте другой ход разговора. Исходная переписка сохраняется; новая ветка получает собственные сообщения и отметку происхождения. Фото доступны в обеих ветках и удаляются только после удаления последней ссылки на них.
- **Память Honor.** Сохраняйте важные факты и предпочтения явно, с возможностью редактирования и удаления. Включённая память добавляется в последующие запросы модели; выключенная остаётся на устройстве и не передаётся в запросах. Поддерживается до 50 записей по 1000 символов. Автоматического скрытого запоминания нет; очистка чатов сохраняет память, для памяти предусмотрено отдельное удаление.
- Фото из камеры и альбома передаются модели как изображения. Текстовые документы и PDF извлекаются на устройстве. Голосовой ввод использует распознавание речи iOS, чтение ответов — системные голоса.
- Поиск получает реальные заголовки, ссылки и выдержки Bing RSS. Ответ учитывает эти выдержки и показывает источники; полные страницы автоматически не скачиваются. Доступность поиска зависит от Bing и сети.
- Настройки: локальное имя, экспорт/импорт переписки и памяти с вложениями, очистка истории, русский/английский интерфейс, тема, размер текста, персональные инструкции, голос и язык диктовки.

История хранится локально. Во время ответа запись JSON выполняется последовательно в фоне с объединением ожидающих снимков, а остановка сохраняет уже полученный текст, включая небольшой буфер вывода. Экспорт и импорт выполняют обработку файлов в фоне. Архив ограничен 100 МБ, включая до 64 МБ файлов; общие фото веток записываются один раз. Импорт объединяет данные, не заменяя существующие чаты и записи памяти.

Синхронизация между устройствами и серверная регистрация аккаунта не добавлены. Генерация может прерваться при уходе iOS-приложения в фон; полученный текст сохраняется и доступен повтор ответа. Приложение не обещает непрерывную фоновую генерацию.

## Сборка

Нужен macOS с Xcode и XcodeGen (`brew install xcodegen`). Откройте `HonorPKAgent.xcodeproj` либо выполните:

```bash
bash scripts/build-unsigned.sh
```

Результат: `build/Honor-PK-Agent-unsigned.ipa`. Если меняются состав или настройки проекта, выполните `xcodegen generate`. На GitHub сборку выполняет workflow `.github/workflows/ios.yml`; ключ берётся из секрета `DEEPSEEK_API_KEY` и включается в ресурс приложения. В исходном архиве для владельца ресурс `HonorPKAgent/DeepSeekConfig.plist` уже настроен.

## Проверки

В `Tests/HonorPKAgentTests.swift` находятся **21 тест логики**: потоковые события и ошибки, русский текст и emoji, формат запросов и изображения, сохранение и восстановление, отмена и поздние токены, импорт, ветки с общими вложениями, память и её выключение, совместимость старых архивов. Отдельные проверки совместимости устройств находятся в `Tests/CompatibilityTests.swift`.

`UITests` проверяют основные экраны и действия на настоящем симуляторе iOS и сохраняют снимки. Для повторяемых сценариев используются явно заданные тестовые ответы, а отдельный тест отправляет реальный запрос в DeepSeek и требует настроенного ключа. Тестовые клиенты и начальные переписки включаются только в Debug и исключаются из распространяемой Release-сборки.

Расширенная проверка версии 1.1 выполняется после изменения кода. Этот README описывает состав тестов, а не утверждает, что ожидающая проверка уже прошла. Итоговые результаты относятся к конкретному номеру сборки и записываются в `VALIDATION.md`.

Установка с сертификатом владельца, физическая камера и микрофон, системные запросы разрешений на реальном iPhone, восстановление после выгрузки iOS и работа в плохой мобильной сети требуют проверки на устройстве. Проверка на одном симуляторе не подтверждает поведение всех поддерживаемых моделей и версий iOS.

Для финального номера сборки, результатов проверки и известных ограничений см. `VALIDATION.md`.
