# Живая проверка Honer AI через настоящий API

Скрипты в этой папке проверяют приложение не догадками, а запросами к тому же API,
который использует само приложение (ключ берётся из `HonorPKAgent/DeepSeekConfig.plist`).

## Файлы

| Файл | Назначение |
|---|---|
| `app-instruction.txt` | Точная копия системной инструкции из `DeepSeekClient.swift` (извлекается скриптом) |
| `live-requests.json` | Набор вопросов для сравнения старых и новых параметров запроса |
| `repro-cases.json` | Воспроизведение жалоб пользователя: «Ку», «Больная чтоли?», таблица телефонов |
| `tools-cases.json` | Проверка версии с параметром `tools` (как было в старых сборках) |
| `run-live-check.ps1` | Прогон `live-requests.json`, замер длины ответа и доли кириллицы |
| `run-repro.ps1` | Прогон любого из наборов: `-CaseFile verify\repro-cases.json` |
| `extract-instruction.ps1` | Извлекает системную инструкцию из исходника, чтобы тест отправлял ровно то же |

## Запуск

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify\extract-instruction.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify\run-repro.ps1 -CaseFile verify\repro-cases.json
```

Скрипты только читают ключ и делают запросы; файлы проекта они не меняют.

## Что уже проверено этим способом

- **Обрыв ответа до одной буквы** (жалоба «просто молчит»): за 12 запросов с точной инструкцией
  приложения плохих ответов **0 из 12** — значит причина в приложении, а не в сервисе.
- **Причина в приложении найдена:** пустой ответ не перезапрашивался, и в чате не появлялось
  ни текста, ни ошибки.
- **Английское рассуждение:** отдельный перевод рассуждения отменялся внутренней проверкой,
  которая использовала порог для ответа. Проверка переписана: обрыв определяется по
  незаконченному предложению, а не по длине.
